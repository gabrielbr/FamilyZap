# Audit · v0.51.0 · the Lista view, fixed

- **Date:** 2026-11-21
- **The owner:** "List view of contacts seems broken. Do some audit. Some errors I found: it does not take full width; time of last message is not aligned with end of line; there is no line separating each row, making it confusing."
- **What changed (`KidHome.kt`):**
  - the Lista column fills the width (the 600dp cap is gone for Lista);
  - the top line of a row is the name and heart in a weighted row, then the time, so the time ends the row above the "N novas" tag;
  - a 1dp `line` hairline between plain rows, inset from the text's start to the time's end;
  - rows with news keep their coral edge and get `space1` of air above and below instead of a line.
- **Skills used and how:** the four skills (ux-user-flows, impeccable with `reference/audit.native.md` against `reference/android.md`, graphic-design-fundamentals, less-is-more) were loaded and read in this session. ux-user-flows updated `docs/flows/kid-home-and-attach.md` (v0.51). The others were run on the re-recorded screenshots: tablet `80-kid-home-list-light` and `83-kid-home-unread-dark`, phone `p01`, `p02` (1.3× text), `p49`, `p50` (1.3× text), `p55`, `p57` and `p61`.

## 3. graphic-design-fundamentals (§13)
- **Alignment ✅:** one left edge for the text (names, previews, line start) and one right edge (time, tag, line end), the same in cards and plain rows.
- **Proximity ✅:** the line groups each photo with its own text.
- **Hierarchy ✅:** the line is the quietest thing on the screen; coral stays for news.
- **Spacing ✅:** tokens only (`space1`, `space3`, `space4`, `avatar`, `hairline`).
