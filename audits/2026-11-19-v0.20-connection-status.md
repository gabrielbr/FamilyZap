# Audit · v0.20 · the tablet said "desconectado" while WhatsApp said connected

- **Date:** 2026-11-19
- **Trigger:** the owner's report: the link connects and the contacts arrive, but after a while the tablet shows "disconnected", while WhatsApp still shows the tablet as connected.
- **Process:** the owner's rule.
  - Design first: `docs/flows/parent-setup-link.md`, section "v0.20".
  - Develop, with tests:
    - `LinkStart`, 3 tests;
    - Go `alreadyUp` and `IsConnected`, 2 tests.
  - Audit with the four skills (loaded and read this session: ux-user-flows, impeccable `audit.native.md` with `android.md`, graphic-design-fundamentals §13, less-is-more).
  - Then docs and ship.
- **Screens:** none change. The screenshot suite still passes unchanged (tablet and phone, light and dark). What changes is *which* state they show, and when.

## Cause
`MainActivity.onStart` restarts `LinkService` each time Oiê comes back to the screen (and when the tablet is turned). The service called `RealLink.start()`, which asked whatsmeow to connect. With the connection already up, whatsmeow answered `ErrAlreadyConnected`. The app caught it as "connect failed" and set **Disconnected**, while the link went on working. WhatsApp's list of linked devices kept showing the tablet, as it does for any linked device.

## Fix
- **Go:**
  - `Connect()` treats "already connected" as success and emits `connected` when it is logged in;
  - new `IsConnected()`;
  - keep-alive misses and restores are reported.
- **App:** `start()` asks `isConnected` first, via `LinkStart.decide`:
  - up and shown as connected → nothing;
  - up but shown as disconnected → shown as connected;
  - down → reconnect.
  - "Conectado" no longer flickers to "Conectando" on each return.
  - A QR on screen isn't restarted by returning to the app or turning the tablet. That was the same mistake in the pairing step.
- **Nothing hides a real drop.** A real disconnect still sets "desconectado", whatsmeow still reconnects by itself (bounded, rule L5), and the app still reconnects when the network returns or Oiê opens.
