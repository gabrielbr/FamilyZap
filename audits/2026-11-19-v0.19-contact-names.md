# Audit · v0.19 · a name for the kid, and the number for the parent

- **Date:** 2026-11-19
- **Trigger:** the owner asked (2026-11-19):
  1. when adding people, set a friendlier name for the kid ("my parents are saved under their names; for my kid they're grandpa and grandma");
  2. show each contact's number in the parent area, to be sure the right person was added.
- **Process:** the owner's rule.
  - Design first: `docs/flows/contacts-quiet-hours.md`, section "v0.19: a name for the kid, and the number".
  - Develop, with tests:
    - `ContactNames` (rename, number, search, display), 8 tests;
    - `ContactsJson` and `PersistenceTest` extended;
    - Go `phoneDigits` and `phoneOf`, 2 tests.
  - Audit with the four skills, each loaded and read this session:
    - ux-user-flows;
    - impeccable (`audit.native.md`, scored against `android.md`);
    - graphic-design-fundamentals §13;
    - less-is-more.
  - Then fix, docs and ship.
  - Decision 0004 records where the names live.
- **Screens looked at:**
  - tablet: 23 (Contatos renamed, light and dark), 24 (editor, light and dark), 25 (setup, picked), plus the changed 09, 13 (portrait), 15, 18 and 20b;
  - phone at 360dp and 1.3× text: p14, p15, p16, p05.

## Found and fixed during the audit
| # | Finding | Severity | Fix |
|---|---|---|---|
| 1 | **Setup on a phone at 1.3×:** "Mudar nome" at the row's end squeezed the name and number into a column one word wide. | P0 (setup is unusable on a phone) | "Mudar nome" sits under the number, aligned with the name. |
| 2 | **Contatos on a phone at 1.3×:** with the switch and Remover on each row, the number was cut ("+55 11 98765-…"), which defeats the owner's ask. | P1 | Remover moved into the contact's editor ("Remover Vovó dos contatos"), with the same undo. The number now shows whole. |
| 3 | A number could break across lines ("+55 11 / 98765-0001"). | P2 | No-break spaces inside the number (tested). |
| 4 | The editor's help packed the WhatsApp name, the number and the blank rule into one sentence that wrapped badly on a phone. | P2 | The WhatsApp name and the number get their own lines above the field; the help says only what blank does. |
| 5 | "Maria Silva no WhatsApp" shared a line with the number and was cut on a phone. | P2 | Its own line, up to 2 lines. |
| 6 | The parent area closes after 2 minutes without a touch; typing a name didn't count as a touch. | P2 | Typing in the editor counts as a touch. |
| 7 | The "tap someone…" hint was permanent (less-is-more: no permanent hints). | P2 | It shows until the parent opens a contact once (saved). The Help answer "Quem pode falar com Tito?" now says how to rename and remove. |
| 8 | Found in passing: About still said "uses example data and doesn't really link to WhatsApp yet", untrue since v0.12. | P2 (pre-existing, misleading) | "Oiê 0.19.0, versão de teste. Usa o seu WhatsApp de verdade." |

No P0 or P1 is open.

## ux-user-flows
§13 checklist: see the flow file (all ✅; evidence 🟡, the owner's test).
- **Happy path:**
  - Contatos: tap the person, type, Salvar;
  - setup: Mudar nome, type, Salvar;
  - adding stays one tap, and renaming is never forced.
- **Heuristics:**
  - #6 recognition over recall: the WhatsApp name and the number are shown in the editor.
  - #3 control: Cancelar, Back and undo.
  - #5 error prevention: a blank name can't be saved as blank.
- **Removal** now costs one more tap (open, then Remover). It's a rare action, and the undo is kept. Accepted (less-is-more, question 5).

## graphic-design-fundamentals §13
1. **Hierarchy:** the name the kid sees leads (label). The number and the WhatsApp name are captions in `muted`, so the squint test reads the name first.
2. **Alignment:** "Mudar nome" and "Remover…" are pulled back by their own padding, so their text lines up with the name above (fixed in this pass).
3. **Spacing:** all from the scale.
4. **Typography:**
   - one family, roles only;
   - numbers are grouped for reading (+55 11 98765-0001) and never split.
5. **Colour:** the coral is used once, on Salvar. Contrast pairs are unchanged (ink and muted on page/surface).
6. **Simplicity:** see less-is-more.
7. **Real size:** checked at 360dp with 1.3× text and on the tablet.
