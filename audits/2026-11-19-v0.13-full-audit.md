## impeccable · native audit (Android)

| # | Dimension | Score | Key finding |
|---|---|---|---|
| 1 | Accessibility | 3 | Labels on every control, 48dp targets, sp type that scales (1.3× checked). Open: TalkBack order on a device. |
| 2 | Performance | 3 | Lists are short (allowed contacts, ≤30 search results); the chat uses LazyColumn; photos are decoded at thumbnail size. The APK is ~21 MB per architecture because of the WhatsApp link. |
| 3 | Appearance & theming | 4 | Every colour comes from `OTokens` (light and dark); no literals in screens. The QR stays ink-on-white in both themes by design. |
| 4 | Platform conformance | 3 | System Back always works (BackHandler); edge-to-edge with safe-drawing insets; Material switches and text fields. The parent tab row is custom rather than Material's navigation, kept to match the design system (P3). |
| 5 | Adaptivity | 3 (was 1) | Before the fixes, phone width was broken in the chat and the parent area (P0 on phones). Now there are two layouts at the 600dp breakpoint, and both orientations are covered by screenshots. Not checked: foldables. |
| **Total** | | **16/20** | **Good.** It was 12/20 before this audit's fixes. |

**Platform conformance verdict:** pass. It reads as a native Android app: Material controls, system Back, notifications on their own channels, and a foreground service with the type Android 14 requires.

**Findings by severity:**
- **[P0 → fixed]** Chat composer collapses at phone width (Adaptivity). `ui/kid/Conversation.kt`. Fixed with `sideMargin` and a non-wrapping time.
- **[P0 → fixed]** Parent area content column has no room at phone width (Adaptivity). `ui/parent/Parent.kt`. Fixed with stacked tabs.
- **[P1 → fixed]** Setup buttons squeezed (Adaptivity). `ui/setup/Setup.kt`. Fixed with `ButtonRow`.
- **[P1 → fixed]** The quiet switch's meaning was hidden or untrue (Accessibility, status). Fixed with a state line.
- **[P1 → fixed]** Irreversible unlink with no confirmation (Conformance: dialogs only for decisions that must interrupt; this is one). Fixed with an inline confirmation.
- **[P2 → fixed]** Contatos right after linking showed only the groups, with the explanation tucked into the search help. Now one line, "Carregando seus contatos do WhatsApp…", shows while no people have arrived yet.
- **[P2 open]** A long contact name in the parent list is cut with an ellipsis on a phone. Acceptable; the kid's home shows the full name.
- **[P3 open]** The parent tab row is custom, not Material navigation. It is kept for consistency with the design system's look.

**Positive findings:**
- Tokens only, and both themes are first-class.
- One coral action per screen holds everywhere checked.
- Undo instead of confirm wherever an action can be undone (removing a contact, a period, a message within 5 s).
- Colour is never alone: verdicts, failures and states always have words.
