## 1. ux-user-flows (§13)
- **Happy path ✅:** opening a chat still takes one tap. The person who needs attention is now first, so the kid doesn't have to search.
- **Memory ✅:** the kid's own order is never rewritten. A person returns to their place once read.
- **Conventions ✅:** as in WhatsApp, recent activity comes up.
- **Accessibility ✅:** the label reads the name, "1 nova" and the message. The reading order matches the visual order. Colour isn't alone, because the count is a word and the message is in bold.
- **Evidence 🟡:** Tito notices the new card.
