# Audit · v0.54.0 · the intro message for every new WhatsApp link

- **Date:** 2026-11-22
- **The owner:** "If the father decides that the mother will be the bridge, so they disconnect and connect again, the first message when they send to anyone should again send the first automated text mentioning that they are using Oiê … it must happen for every new WhatsApp connection."
- **Found:** the chats already introduced were kept for ever (v0.47, "once per chat, ever"). After a switch to another parent's WhatsApp, nobody was told again.
- **What changed:**
  - **Where the reset happens:** `AppState.forgetIntros()` runs on every pairing (the link's `paired` event), on Desconectar o WhatsApp, and on a PIN remake.
  - **The account check:** `introducedBy` remembers which WhatsApp sent the intros, and is saved. Before every first message, `Intro.accountChanged` starts the list over if the tablet is on another WhatsApp. This covers a link made in setup, before any event was seen.
  - **Copy:** the Ajustes line now says it explains again after each new link (PT and EN).
  - **Tests:** `IntroTest` gets 4 new tests, and `PersistenceTest` checks that `introducedBy` is saved.
  - **Docs:** the flow `docs/flows/intro-message.md` (v0.54), CHANGELOG, STATUS.
- **Skills used and how:** the four skills were loaded and read in this session. ux-user-flows updated the flow first. The other three were run on the changed screenshots (`77-parent-settings` light and dark, `16`, `30`, `54`, and phone `p07`, `p12`).
