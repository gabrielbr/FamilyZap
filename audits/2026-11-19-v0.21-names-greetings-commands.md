## ux-user-flows
§13 checklist: in `docs/flows/parent-commands.md` (all ✅). Two items are 🟡, to be settled by the owner's test:

- how families react to seeing the "/Tito" message.
- **Heuristics:**
  - #1 status: every command gets an answer, even an unknown word ("não entendi"), and help says what the chat is now.
  - #3 control: every command has its undo, and Contatos can resume a chat too.
  - #6 recognition: "/Tito" alone lists everything.

  - still private: the name later in the sentence ("Oi, o Tito está aí?"), and two greetings ("Oi oi Tito").
  - All tested.

## Product law and privacy
- Only the parent's account can change who reaches the kid.
- A paused chat reaches the kid in no way.
- Command text isn't stored. The report says only "command: pause → paused".
- Rule L2 gains one exception (decision 0005): Oiê's answers go to the parent's own chat. The kid can never write there.
