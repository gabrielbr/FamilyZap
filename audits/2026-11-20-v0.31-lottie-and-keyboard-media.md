# Audit · v0.31 · WhatsApp's animated stickers move; media from the keyboard or paste

- **Date:** 2026-11-20
- **Trigger:** the owner's test of v0.30:
  - animated stickers from WhatsApp's own packs stay still;
  - GIFs from Gboard, and pasted media, can't be put in the text field.
  - Lottie was approved by the owner (decision 0008).
- **Process:** the owner's rule.
  - Design first: `docs/flows/kid-receives-messages.md` and `docs/flows/kid-sends-message.md`, sections v0.31.
  - Develop, with tests:
    - `PastedTest` (routing by type);
    - `MovingTest` extended (Lottie zips, the kind for the report);
    - Go `TestALottieStickerGoesBackAsLottie`.
  - Audit with the four skills (loaded and read this session); docs; ship.
- **Screens:** the chat's goldens are re-recorded. The new text field differs from the old by a few antialiased corner pixels only (the compare images were checked). Lottie playback and keyboard content need the device: the owner's test is the evidence.

## Causes
1. **Stickers:** WhatsApp's store packs are Lottie animations (`application/was`, a zip). v0.27 handled animated WebP only. A Lottie file isn't a bitmap, so it fell back to the still preview.
2. **Keyboard media:** the field was the value-based Material text field, which doesn't receive rich content. Gboard offers GIFs and stickers only to fields that declare they accept them, and paste only carried text.

## Fix
- **Stickers:**
  - Lottie stickers are drawn with Lottie, in the chat and the sheet; "Remove animations" keeps them still;
  - saved ones go back out as Lottie (`IsLottie`, `application/was`);
  - the report logs each sticker's kind.
- **Keyboard media:**
  - the composer is Compose's state-based `BasicTextField` with `contentReceiver`, styled exactly as before;
  - GIFs go to the GIF preview, pictures and keyboard stickers to the photo preview, videos to the video preview;
  - the file is copied at once (the keyboard's read permission is short) and nothing is sent without Enviar.

## ux-user-flows
- **Conventions (#4):** Gboard's GIFs and stickers, and paste, now work as in every messaging app.
- **Control:** every route ends in its preview, with Trocar and Back; text paste still pastes text.
- **Errors:** an unreadable file shows the photo message ("Não deu para abrir…"), and the report says why.
