# 0002 · Name: Oiê

- **Date:** 2026-11-18
- **Status:** approved
- **Approved by:** the owner, 2026-11-18, in the Claude session

## Context
The working name FamilyZap leaned on "Zap", what Brazilians call WhatsApp. The brand must never
imply it's a WhatsApp product (Stage 2 "never implies"), so the owner asked for new names that
work in Brazilian Portuguese and English.

## Decision
**Oiê.** Brazilian Portuguese for a warm, playful "hi!", the first word of most family messages.
Said **"oy-YEH"** (PT: /oj'e/). In plain text without accents, write **Oie**.
- Android application id: **`app.oie`** (permanent; never renamed).
- Home domain: **oie.app** (free on 2026-11-18; the owner registers it).
- Project code: **OIE** (was FAM). Repo: `gabrielbr/oie` (the owner renames it on GitHub).

## Known risk, accepted by the owner
The Brazilian telecom **Oi** has an app called **"Oi_e"** (for Oi Fibra customers). It sounds
almost the same and is also about communication in Brazil. That risks confusion and a trademark
objection. The owner chose to keep Oiê and accept the risk. Mitigation: always write the name
with the circumflex and never use Oi's colours, underscore or logo shapes; search INPI (classes 9
and 38) before the first public release.

## Options considered
| Option | Why not |
|---|---|
| FamilyZap | "Zap" means WhatsApp in Brazil, against "never a WhatsApp product" |
| Perto, Colo, Ninho, Colinho, Kindo | the .app domain is already registered |
| Amorinho | hard to say in English; .com.br taken |
| Recadim | regional; hard in English; .com and .com.br taken |
| Achego | little-known word; .com taken |

## Consequences
- Rename FamilyZap to Oiê everywhere (done in this change); code OIE in file names.
- Owner to do: register oie.app; rename the GitHub repo to `gabrielbr/oie`; check Instagram and
  TikTok handles; search INPI before release.
